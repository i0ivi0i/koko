# 风格与约束
- 命名、注释与很多模块职责说明以中文表达，要求高密度且直接。
- 默认优先复用成熟生态，不手搓基础设施轮子；实时主通道保留 `socketioxide`。
- 严守分层：domain/application(contract/usecase)/adapter/shell；前端不承载权限、成员资格、消息成立等业务真相。
- `contract` 是跨端共享唯一表面；禁止混入壳层展示文案、页面流程、UI 状态语义。
- adapter 只翻译协议和错误，不写业务规则；shell 只做交互编排和必要本地状态。
- 默认 TDD：功能开发、缺陷修复和重要重构先补失败测试，再最小实现，再转绿。
- 修改代码前要重新读取目标文件并先搜索上下文；默认优先使用 Serena MCP 做符号级搜索、关系分析与精确编辑。
- Rust 侧尽量不新增 `.rs` 文件，长期控制非测试 Rust 文件数；优先收口、删除冗余、避免纯格式化噪音。
- 提交说明使用中文，要求具体、准确、可读。
