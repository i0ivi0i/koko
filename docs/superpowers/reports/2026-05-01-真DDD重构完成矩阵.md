## 1234b 真实浏览器烟测

本轮使用 `run.ps1 -DisableLocalHttpsBootstrap -DisableAutoOptimizeCleanup` 启动本地真实链路，浏览器操作使用 `playwright-cli` 双会话 A/B，trace 使用 `playwright-cli tracing-start` / `tracing-stop` 记录。

| 场景 | 结果 |
| --- | --- |
| A/B 进房 | 两个全新 profile 均从首页输入 `1234b` 进入同一房间 |
| 文本实时增量 | A 发送 `ddd-smoke-final-20260503-1024`，B 在消息流看到同一文本 |

## 当前降级裁决

1. 当前不得宣称三满分。
2. 上一轮重构和 `1234b` 烟测仍是有价值的历史证据，但它们没有覆盖本轮复审发现的全部硬缺口。
3. 必须按 [真 DDD 三满分最终验收规格](../specs/2026-05-02-真DDD满分验收规格.md) 先补齐完成矩阵降级门禁、同步/异步规则复制门禁、总仓储壳门禁、总编排壳门禁和反垃圾门禁。
4. 只有新门禁、全量测试、graphify 更新和 `1234b` 双浏览器真实烟测同时新鲜通过，本矩阵才允许重新升级为完成态。
