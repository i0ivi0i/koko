# 房间外壳拆分瘦身 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 `src/房间外壳.rs` 恢复成真正的房间 HTTP 壳，并在不改协议、不留双轨旧代码的前提下，把媒体相关职责拆到 5 个明确 owner 文件。

**Architecture:** 新文件都作为 `src/外壳.rs` 的私有子模块存在，继续属于 shell 内部接线层，不上升成 crate 公共表面。拆分顺序严格遵守“先纯能力，后 HTTP 壳；先内脏，后路由”，每一轮只搬一簇 owner，并且同提交删除旧实现。

**Tech Stack:** Rust 2021, Axum, Tokio, SQLx, object_store, infer, image, kamadak-exif, ffmpeg/ffprobe/shaka-packager, cargo test, cargo clippy
