# Debian 12 单 VPS 一键部署与升级回滚 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 `koko` 落成一套对电脑小白友好的单 VPS 正式部署主链：GitHub Actions 负责按钮和版本，Debian 12 VPS 负责运行，Cloudflare + 正式域名负责唯一公网入口，并具备首次安装、日常升级、明确回滚三条固定路径。

**Architecture:** 采用 `GitHub Actions -> SSH -> Debian 12 VPS -> Docker Compose + Caddy + app/postgres/tusd/tracker/seeder` 的单主链。仓库内新增 `ops/`、`.github/workflows/`、`Dockerfile`、`.dockerignore` 与部署门禁脚本；版本目录、当前软链接、持久化数据物理分离；禁止 `cloudflared`、禁止第二套运行主链、禁止部署真相漂成“VPS 手工命令 + 仓库脚本”双活。

**Tech Stack:** Rust 2021, SQLx `migrate!`, Axum, pnpm frontend build, Docker multi-stage build, Docker Compose, Caddy, GitHub Actions, PowerShell on Win11 for local verification, Git Bash for shell syntax checks.
