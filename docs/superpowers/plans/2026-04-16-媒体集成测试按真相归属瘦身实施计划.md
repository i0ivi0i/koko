# 媒体集成测试按真相归属瘦身 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不改变任何生产业务语义的前提下，把媒体相关 integration tests 按真相归属重组为“上传主链 / 协作分发读侧 / 后台清理 / 小而专测试支撑”四类边界，彻底停止 `tests/媒体上传测试.rs`、`tests/协作分发测试.rs` 和 `tests/测试支撑/媒体.rs` 继续无边界膨胀。

**Architecture:** 保持 `cargo test --test 媒体上传测试` 与 `cargo test --test 协作分发测试` 两个现有 crate 入口稳定，只把它们改成薄 manifest，再新增 `cargo test --test 媒体后台测试` 承载后台清理 owner。共享测试支撑继续集中在 `tests/测试支撑/`，但 `媒体.rs` 只做薄出口，真正实现按 `tus / seed / fixture` 三类小工具分开，禁止再长成第二套测试业务编排层。

**Tech Stack:** Rust integration tests, Cargo, Tokio, Axum, SQLx/PostgreSQL, PowerShell, graphify

---

## File Structure / Responsibility Map

### New files to create

- `tests/媒体后台测试.rs`
  - 新的 cleanup test crate 顶层 manifest，只声明后台清理相关模块与共享支撑。
- `tests/媒体后台测试/上传残留清理.rs`
  - 承载上传残留 cleanup owner：`partial`、过期 unfinished、历史 rustus locator 收口。
- `tests/媒体后台测试/冷源清理.rs`
  - 承载冷源 / mezzanine cleanup owner 与清理后共享事实验证。
- `tests/媒体上传测试/prepare.rs`
  - 上传 prepare 与旧入口回归。
- `tests/媒体上传测试/complete.rs`
  - 上传 complete 主链与竞态回归。
- `tests/媒体上传测试/abandon.rs`
  - abandon 与 termination 协调。
- `tests/协作分发测试/读接口契约.rs`
  - locator / torrent / range 读取契约。
- `tests/协作分发测试/投影一致性.rs`
  - locator 与 snapshot / attachment snapshot 的投影一致性。
- `tests/协作分发测试/可用性裁决.rs`
  - presence 驱动的 availability / expired 裁决。
- `tests/测试支撑/媒体/tus.rs`
  - tus hook 请求体构造、prepare 契约断言、Tus hook 断言。
- `tests/测试支撑/媒体/seed.rs`
  - 直接建 ready attachment / distribution / manifest 的测试建数小工具。
- `tests/测试支撑/媒体/fixture.rs`
  - `tus` 临时文件、最小 PNG/MP4 fixture。

### Existing files to modify

- `tests/媒体上传测试.rs`
  - 从具体测试容器改成薄 manifest，只保留模块声明、共享支撑导入、边界注释。
- `tests/媒体上传测试/tus_hook.rs`
  - 继续保留现有 Tus hook owner，不迁到后台清理或分发 crate。
- `tests/媒体上传测试/公网地址推导.rs`
  - 继续保留公网地址推导 owner，不与上传主链混写。
- `tests/协作分发测试.rs`
  - 改成薄 manifest，只保留模块声明、共享支撑导入、边界注释。
- `tests/测试支撑/媒体.rs`
  - 从实现大文件改成薄出口，`pub use` 子模块。
- `tests/测试支撑/mod.rs`
  - 如有必要，仅补注释说明 `media` 已收口成薄出口；不改变外部模块名。
- `docs/superpowers/specs/2026-04-16-媒体集成测试按真相归属瘦身-design.md`
  - 如果迁移中发现文件映射必须微调，再同步 spec；否则不动。

### Constraints

- 不改任何 `src/*.rs`
- 不改任何已有断言语义，除非为了修正迁移导致的 import / helper 可见性问题
- 不引入 `TestWorld`、`测试服务`、`测试仓储`、`万能 builder`
- 不为“去重”新增第二套测试 DSL
- 顶层 manifest 文件不再继续定义大量 `#[tokio::test]`
