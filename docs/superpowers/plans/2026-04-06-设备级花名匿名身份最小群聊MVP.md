# 设备级花名匿名身份最小群聊 MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 `koko` 从“已有单节点 realtime 主链基础”推进成一个真正可进入 MVP 测试的最小群聊产品：打开 Web 后自动恢复同一设备的稳定花名身份，输入合规房间码即可进入房间页并实时聊天，同时继续守住后端单一真相、单一 `event_position` 锚点和明确失败语义。

**Architecture:** 继续坚持多壳共核与 DDD 边界。`domain / application` 持有匿名内部身份、房间成员资格、消息成立和事件锚点；`contract` 定义跨壳稳定命令、查询、事件、快照和错误码；`adapter` 负责 HTTP / realtime 协议翻译、鉴权接入、IO 编排；Web 只是第一个壳，`localStorage` 只保存设备入口凭证，不保存最终身份真相。`socketioxide` 继续当 realtime 二副，不篡位成业务船长。

**Tech Stack:** Rust, axum, socketioxide, sqlx/PostgreSQL, TypeScript, socket.io-client, Vitest, Tokio, tracing
