# Web 首页会话列表唯一键与去重语义修复 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复首页会话列表把同一 `roomCode` 渲染成两条的问题，并让旧脏本地数据在读取时自动收口。

**Architecture:** 首页历史继续只由 `frontend/存储.ts` 持有真相，去重逻辑不下放到壳层。当前群聊阶段把首页列表的唯一键从内部 `roomId` 收口为用户可感知的 `roomCode`，同时保留最新记录里的 `roomId` 作为恢复与进房入口。

**Tech Stack:** TypeScript, Lit, Vitest, localStorage browser adapter

---

## 文件结构与职责

- `frontend/存储.ts`
  - 首页历史列表的唯一 owner
  - 负责读取、规范化、去重、排序、写回
- `frontend/tests/聊天壳测试.spec.ts`
  - 锁住存储层读取/写入/旧脏数据收口
- `frontend/tests/聊天壳引导与入房测试.spec.ts`
  - 锁住首页渲染和进房后房间历史展示

本次不改：

- `frontend/房间恢复编排.ts`
- 后端房间模型
- 首页 UI 结构

```ts
const byRoomId = new Map<string, 首页房间历史条目>();
```

改成：

```ts
const byRoomCode = new Map<string, 首页房间历史条目>();
const current = byRoomCode.get(roomCode);
if (!current || item.lastEnteredAt >= current.lastEnteredAt) {
  byRoomCode.set(roomCode, {
    roomId,
    roomCode,
    lastEnteredAt: item.lastEnteredAt,
  });
}
return Array.from(byRoomCode.values()).sort(
  (left, right) => right.lastEnteredAt - left.lastEnteredAt
);
```
