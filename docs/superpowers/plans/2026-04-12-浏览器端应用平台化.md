> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有 `BrowserAppPlatform / ChatAppKernel / AdminAppKernel` 骨架上，完成 [2026-04-12-浏览器端应用平台化-design.md](E:/koko/docs/superpowers/specs/2026-04-12-浏览器端应用平台化-design.md) 定义的收尾：收紧 owner 真相、删掉共享 patch 总线、补齐平台运行时、压薄壳层。

**Architecture:** 这不是从零开始的新建计划，而是当前代码状态下的收尾计划。后续每一刀都只能做“真实 owner 收口 + 同步删旧入口”，不允许继续叠 wrapper、兼容口或第二套真相；聊天侧先收真相 owner，再补平台 runtime，再清后台展示边界和测试旁路。

## 全局红线

- 不允许再往 `聊天状态` 加字段后继续用 `更新状态(patch)` 扩容。
- 不允许壳层继续新增除 `snapshot()/dispatch()/dispose()` 之外的正式业务入口。
- 不允许 platform runtime 直接判断房间、未读、消息成立。
- 不允许继续保留“新接口 + 旧旁路”双活超过一个任务。
- 不允许只加 wrapper 不删旧路径。
- 不允许没有失败测试就改 core 行为。
- 不允许用测试 setter / 直改内部状态代替真实命令或 fake adapter。
