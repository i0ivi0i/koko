# 聊天壳单屏布局与软离房 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把前端聊天壳改成 Telegram iOS 风格的单屏聊天界面，补上“软离房”返回语义，并让标题显示房间短码而不是内部 `room_id`。

**Architecture:** 这次只改前端壳层，不动 Rust 后端真相。`room_id` 仍然是恢复锚点，新增的 `room_code` 只作为壳层本地展示缓存，和 `koko_current_room_id` 并列保存在 `localStorage`。返回按钮固定切回搜索视图并断开当前房间 socket，不依赖浏览器历史栈，也不新增任何后端离房命令。

**Tech Stack:** Lit 3、TypeScript 6、Vitest 4、happy-dom、localStorage 壳层持久化

## 计划备注

1. 短码显示缓存固定落在 `localStorage`，键名建议为 `koko_current_room_code`，这样和 `koko_current_room_id` 同层管理，刷新后仍可恢复标题。
2. “返回”固定实现成壳层内部切回搜索页，不依赖浏览器 back。
3. 如果实现过程中发现当前 `假Socket` 测试替身不便于断言 `disconnect()`，只允许在测试替身里补最小可观测性，不要顺手扩协议。
