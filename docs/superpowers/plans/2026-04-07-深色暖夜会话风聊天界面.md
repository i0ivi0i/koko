# 深色暖夜会话风聊天界面 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把当前前端聊天界面重构成只支持深色模式的“暖夜会话风”群聊 IM，借用 `DESIGN.md` 里的温暖色彩、圆角和材质感，但彻底去掉普通网页感。

**Architecture:** 这次只改 Web 壳层的全局视口契约、房间页视觉层次、搜索页入口视觉和相关测试，不改 Rust 后端真相、不改共享契约、不改消息语义。全局上先锁死 `html/body` 与聊天壳的单屏关系，再把 `聊天壳.ts` 里的视觉 token、结构和文案状态统一收口到“暖夜会话空间”语言。

**Tech Stack:** Lit 3、TypeScript 6、Vitest 4、happy-dom、原生 `index.html` 入口、CSS 自定义属性

## 计划备注

1. `DESIGN.md` 只能借“暖感、圆角、材质、强调色克制使用”，不能把 Airbnb 的白底浏览型网页骨架带进来。
2. 这次默认只支持深色模式，不做明暗双主题切换。
3. 房间页和搜索页都必须继续服从《聊天 IM 反网页化设计宪法》里的裁决条款。
4. 如果执行时发现 `frontend/index.html` 的全局样式还不够锁死视口，可以补 `body > koko-chat-shell { display: block; width: 100%; height: 100%; }` 这类最小规则，但不要额外发明全局页面布局系统。
