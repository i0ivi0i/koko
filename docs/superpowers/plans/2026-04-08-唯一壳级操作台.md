# 唯一壳级操作台 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把当前“同一位置上的两套底部条”收成整个前端里唯一的壳级操作台：boot/home/room 都共用同一套常驻骨架、同一个主 form、同一个主输入、同一个主动作，只切换模式语义与提交目标。

**Architecture:** 继续保留 [frontend/聊天壳.ts](/E:/koko/frontend/聊天壳.ts) 作为唯一主壳，不改 Rust 后端、不改房间恢复/订阅主链。新增 `ShellConsoleState` 级别的壳层 presenter 派生，`ShellConsole` 继续作为代码名，但中文术语统一使用“操作台”；`hidden/join/message` 都只能驱动同一套常驻 DOM 骨架，而不能各自渲染自己的 form。

**Tech Stack:** Lit 3、自定义元素、TypeScript、Vitest、happy-dom、本地 `localStorage`、现有 presenter 层 [frontend/视图.ts](/E:/koko/frontend/视图.ts)
