# Startup 启动输出统一 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 Rust 成为唯一启动语义真相源，统一承担首页地址、管理入口、管理员口令与一次性 notice 的输出；保留 Rust 技术日志用于排障；把 `run.ps1` 收缩为只做开发期准备、stdout/stderr 直通与可选浏览器打开的薄启动器。

**Architecture:** 本次先收“谁输出、何时输出、脚本还能不能复述”这条主轴，不先扩成 bind/config/network 改造。`src/support.rs` 负责启动横幅事实、渲染和必要展示 helper；`src/main.rs` 只负责 ready 时机；`run.ps1` 删除部署语义，只保留准备、启动、直通和可选 auto-open。地址展示细化如果仍有缺口，放到最后作为展示层补丁，而不是反向主导整个任务。

**Tech Stack:** Rust 2024, tokio, axum, tracing, PowerShell 5, cargo test

fn run_root_script(args: &[&str]) -> std::process::Output {
    let _guard = env_lock();
    let powershell = powershell_exe_path();
    std::process::Command::new(powershell)
        .args(["-ExecutionPolicy", "Bypass", "-File", "run.ps1"])
        .args(args)
        .env("PATH", r"C:\Windows\System32")
        .env_remove("PSModulePath")
        .env_remove("PATHEXT")
        .env_remove("PROMPT")
        .current_dir(env!("CARGO_MANIFEST_DIR"))
        .output()
        .unwrap()
}
