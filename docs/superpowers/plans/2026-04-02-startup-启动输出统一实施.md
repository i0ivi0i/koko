# Startup 启动输出统一 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 Rust 成为唯一启动语义真相源，统一输出首页地址、管理入口、管理员口令与一次性 notice，保留 Rust 技术日志用于排障，并把 `run.ps1` 收缩为只做开发期准备、stdout 直通与可选浏览器打开的薄启动器。

**Architecture:** 启动横幅相关事实和派生规则集中在 `src/support.rs`，`src/main.rs` 只负责启动编排并在 ready 时机触发横幅输出。`run.ps1` 删除地址/口令/横幅计算逻辑，改成直通 Rust 输出、只从 Rust 已打印的首条首页地址行解析 auto-open URL，并通过负向测试锁死“脚本自身不再输出部署语义”。

**Tech Stack:** Rust 2024, tokio, axum, tracing, PowerShell 5, cargo test
