# 数据库迁移单一基线 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 `migrations/` 从 21 个探索期 SQL 收口成一个当前 PostgreSQL schema 基线，并加门禁防止未来无意识膨胀、低性能索引和冗余数据库真相。  

**Architecture:** 数据库 baseline 只表达当前 adapter 查询实际需要的 schema；domain / application / contract 不动。迁移测试从“历史文件存在”改成“空库最终结构正确 + 迁移目录数量受控 + 索引有真实路径依据”。  

**Tech Stack:** Rust 2021, PostgreSQL, SQLx 0.8 `migrate!`, Tokio, Cargo integration tests, PowerShell on Win11.

---

## 0. Context

Spec: `docs/superpowers/specs/2026-05-04-数据库迁移单一基线设计.md`

User-approved premise:

1. 当前数据库可以丢弃重建。
2. 旧 21 个 migration 不保留归档，Git 历史已足够。
3. 不能引入业务 bug。
4. 不能生成低性能、低效率、冗余、垃圾数据库结构。

Official constraints already folded into spec:

1. PostgreSQL 官方支持一个 `ALTER TABLE` 合并多个动作以减少扫描/重写。
2. 大表加约束用 `NOT VALID` / `VALIDATE CONSTRAINT` 降低并发影响。
3. 生产建索引用 `CREATE INDEX CONCURRENTLY`，但它不能在普通事务块内执行。
4. SQLx 会用 `_sqlx_migrations` 记录 hash；已应用过的迁移不能随便改，但本轮旧库可重建。

## 4. Task 2: Write The Single Baseline

- [ ] **Step 1: build baseline from final schema only**

Use old migrations as input, but write final DDL directly:

```sql
CREATE TABLE IF NOT EXISTS anonymous_identities (...);
CREATE TABLE IF NOT EXISTS sessions (...);
...
```

Required rules:

```text
Use BIGINT GENERATED ALWAYS AS IDENTITY for internal surrogate ids.
Use TEXT for strings.
Use TIMESTAMPTZ for timestamps.
Use CHECK constraints for stable finite business values.
Do not use JSONB for core relations.
Do not create partitions.
Do not include historical transition objects.
```

- [ ] **Step 2: preserve final business constraints**

Must include:

```text
rooms.room_id UNIQUE

attachment_upload_sessions upload_token UNIQUE

swarm_peer_presence PRIMARY KEY (swarm_id, session_id, peer_kind)

canonical_media_assets storage_key UNIQUE
attachment_source_hashes CHECK source_hash format, but no global UNIQUE(source_hash)
```

```rust
#[serial]
async fn 当前数据库基线可在空库建立完整结构() {
    let base_database_url = koko::assembly::读取配置()
        .expect("需要本地 DATABASE_URL")
        .database_url;

    let expected_tables = [
        "anonymous_identities",
        "sessions",
        "rooms",
        "room_members",
        "room_events",

        "attachment_source_hashes",
    ]
    .into_iter()
    .map(String::from)
    .collect::<Vec<_>>();

    let table_count: i64 = sqlx::query_scalar(
        "SELECT COUNT(*)
           FROM information_schema.tables
          WHERE table_schema = 'public'
            AND table_name = ANY($1)",
    )
    .bind(&expected_tables)
    .fetch_one(&pool)
    .await
    .expect("应能查询 baseline 表");

    assert_eq!(table_count, expected_tables.len() as i64);

    pool.close().await;
    删除迁移测试数据库(&base_database_url, &db_name).await;
}
```
