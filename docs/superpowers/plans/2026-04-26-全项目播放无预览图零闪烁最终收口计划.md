# 全项目播放无预览图零闪烁最终收口计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让新旧所有用户会话在进入群聊、回到群聊或持续滚动消息流时，当前可见与即将进入视口的视频都能在不依赖后台静态预览图的前提下，先收敛成稳定预览，再无闪烁无抽搐地进入自动播放；禁止任何非 owner 卡片把正式 playback 源在 `0s` 冷停着冒充预览。

**Architecture:** 这次不再修表面遮挡，而是把两条根因一起收口到 `聊天媒体编排 -> 视频预览协作 -> 房间消息窗` 三段链上。核心裁决是：可见/预热窗口内的视频，必须把 preview ready 收敛视为高优先级事实；`missing_source` 不能在同版会话里无限躺平直到 autoplay owner 触发；同时房间消息窗必须禁止把 `swarm playback.src` 泄漏成非 owner 卡片的可见预览底板。

**Tech Stack:** TypeScript, Lit, Vitest, Playwright, Serena symbols, Video.js singleton owner chain
