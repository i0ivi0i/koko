# Koko 第一轮治理战役 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把第一轮治理战役里的三项正式问题全部收口：收回 admin 判权与共享面边界、收回 `join_or_create_room_by_code` 的权威事实归属、收口重复测试支撑和低价值源码文本断言。

**Architecture:** 这不是一次大重写，而是三刀连续收口。第一刀只修 `admin` 共享面与判权，先把错误边界从对外表面剥掉；第二刀再把 `room entry` 的创建事实从 `store` 拉回 `application`；第三刀把测试层从“保护当前写法”改成“保护行为和边界”，同时合并重复 harness。所有改动都必须走 TDD，且每刀单独提交。

**Tech Stack:** Rust 2024, Axum, Dioxus, Reqwest, SQLx/Postgres, Tokio, serde, thiserror, uuid, chrono.

---

## File Responsibility Map

- `src/contract.rs`: 多壳共享命令、查询、快照、事件和错误码；本轮要删掉页面型 admin DTO，并补齐稳定 admin 错误语义。
- `src/app.rs`: 应用层用例和 port 定义；本轮是主战场，要新增 admin 访问裁决边界，并收回 room entry 的事实创建权。
- `src/domain.rs`: 纯业务语义；本轮只在 room entry 事实显式化时补最小必要的结构，不引入框架依赖。
- `src/store.rs`: SQLx adapter；本轮要把 admin 查询改成“授权后读取”，并从“自己生成房间/成员事实”收回到“只持久化应用层已决定的事实”。
- `src/http.rs`: HTTP adapter；本轮要删掉 `/api/admin/panel`，把 admin token 从“入口层最终裁决”改成“入口层提取并传给应用层”。
- `src/support.rs`: 配置与跨层支持；本轮可承载静态 admin 授权 adapter，但不能重新长成万能垃圾桶。
- `src/admin.rs`: Web admin 壳；本轮要从单个 `panel` 接口改成组合 `overview + rooms`。
- `tests/app_flow.rs`: 应用层和 store 集成测试主战场；本轮要新增 admin 授权边界测试和 room entry 事实归属测试。
- `tests/admin_flow.rs`: admin 壳与 admin HTTP 行为测试；本轮要删掉源码文本断言，改成真正的行为保护。
- `tests/http_flow.rs`: HTTP/浏览器壳行为测试；本轮要补 `/api/admin/panel` 下线后的稳定行为守护。
- `tests/http_support/mod.rs`: 现有 HTTP 测试支撑；本轮将被提升为真正共享的 DB/HTTP 支撑，供 `app_flow` 复用。

```rust
#[derive(Debug, Error, PartialEq, Eq)]
pub enum AppError {
    SessionNotActive { session_id: Uuid },
    NotRoomMember { room_id: Uuid, session_id: Uuid },
    AdminAccessDenied,
    DependencyFailure,
    Domain(#[from] DomainError),
}

pub async fn get_admin_overview<A, P>(
    access_port: &A,
    admin_overview_port: &P,
    context: AdminQueryContext,
) -> Result<AdminOverview, AppError>
where
    A: AdminAccessPort,
    P: AdminOverviewPort,
{
    if !access_port.is_authorized_admin(&context).await? {
        return Err(AppError::AdminAccessDenied);
    }

    admin_overview_port.get_admin_overview().await
}
```
