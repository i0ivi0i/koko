# 开发启动器重构 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用 `just + xtask` 替换当前 `run.ps1` 开发入口，提供更干净的 Win11 本地开发体验。

**Architecture:** 采用 Cargo-first 入口设计。`just` 作为面向开发者的薄入口，`xtask` 负责真正的环境读取、初始化、开发进程编排和日志输出；`server` 与 `web` 继续只关注服务本身，不感知开发脚本。

**Tech Stack:** Rust workspace, just, xtask, tokio/std::process, Dioxus CLI, Cargo, PostgreSQL, sqlx
