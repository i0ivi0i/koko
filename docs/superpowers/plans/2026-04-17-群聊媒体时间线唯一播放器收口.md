# 群聊媒体时间线唯一播放器收口 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 收口群聊时间线视频附件的播放 owner，先止住整房 eager 解析、重复 locator 和默认 whole-file backfill。

**Architecture:** 保留现有 `媒体会话 -> 媒体播放器 -> 协作分发` 主链，不新造播放器实现。时间线默认只保留静态 poster，视频正式解析只在自动播 owner 或正式查看器触发；`媒体定位器` 负责 attachment 级 inflight 去重；WebTorrent 会话默认只保可播，不默认整文件补齐。

**Tech Stack:** TypeScript、Vitest、Lit、WebTorrent、现有聊天媒体编排/媒体播放/媒体协作分发模块
