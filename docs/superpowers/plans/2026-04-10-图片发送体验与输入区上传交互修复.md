# 图片发送体验与输入区上传交互修复 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把当前图片发送体验修到符合群聊 IM 直觉：小 `+` 直接选图、本地草稿预览稳定、上传中/失败状态明确、发送按钮不再 silent return。

**Architecture:** 保持后端 `HTTP 上传 -> attachment_id -> realtime create_message -> 权威回流` 主链完全不变，这轮只修前端壳层交互。继续复用现有 `Uppy` 内核和 `XHRUpload`，但把主入口从 `Dashboard` 大面板改成原生 `input[type=file] + uppy.addFile()`；草稿预览继续优先使用本地 `object URL`，不再提前切到远端缩略图。

**Tech Stack:** TypeScript、Lit、Uppy、XHRUpload、Vitest、happy-dom、pnpm、PowerShell `run.ps1`
