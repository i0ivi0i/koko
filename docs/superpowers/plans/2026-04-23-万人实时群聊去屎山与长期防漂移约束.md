# 万人实时群聊去屎山与长期防漂移约束 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在继续复用 `socketioxide + socket.io-client` 作为唯一聊天 realtime 主链的前提下，把当前剩余 shared transport/runtime/shell 热点、media/browser-app owner 热点，以及 launcher/bootstrap 共享脚本热点一次性收口到底，并同步建立不会再慢慢养回屎山的验证与退场门禁。

**Architecture:** 这不是新的阶段路线，也不是新的 child spec。阶段一聊天主链守正已经视为既有完成事实；本计划只接管剩余总执行，顺序固定为“先守既有核心和契约，再收 shared owner，再收 media/browser-app owner，最后删旧路径、全量验证、graphify 复核”。整个计划必须持续遵守 DDD / Onion / Unix 约束：业务真相只归唯一 owner，adapter 只做协议翻译，shell/runtime 只做交互编排与本地运行时，不允许再长第二套真相或第二条私有主链。

**Tech Stack:** Rust 2021、Tokio、Axum、socketioxide、TypeScript、Lit、socket.io-client、Vitest、PowerShell、graphify、WebTorrent、Video.js

## 实施前结论与 authoritative 基线

### 1. 这份 plan 接的不是“新阶段”，而是剩余总执行

这份 plan 必须建立在下面这些 authoritative 事实之上：

1. 新总入口已经是 `docs/superpowers/specs/2026-04-23-万人实时群聊去屎山与长期防漂移约束.md`。
2. `docs/superpowers/specs/2026-04-23-万人实时群聊去屎山收口与实时主链守正.md` 只作为已完成聊天主链守正基线继续有效。
3. 后续剩余工作**禁止**再回到“先补阶段二 child spec、再补阶段三 child spec”的旧路线。
4. 当前 implementation plan 的职责，是把剩余 shared / media / browser-app / launcher 热点直接落成一次性总执行步骤，而不是继续讨论阶段数。

因此必须先把一句话写死：

**这份 plan 只负责剩余总执行，不负责重新发明阶段二/三叙事。**

### 2. 当前系统真相，必须作为全部实现前提

后续任何任务都必须同时承认下面两个事实：

1. 聊天 realtime 正式核心仍然是后端纯 Rust `socketioxide` + 前端 `socket.io-client`。
2. 当前真正要清的，不是成熟核心轮子，而是围绕成熟核心长出来的私有重复轮子、私有重复真相、私有重复胶水和热点总控。

只要脱离这两个前提，后面就很容易走偏成两种错误：

1. **误杀成熟核心轮子**
2. **低估外围私有胶水屎山**

这两种都必须禁止。

## 结构收口阶段的测试解释

这次不是凭感觉重构，而是**带护栏的总收口**。测试分成两类，执行时禁止混淆：

1. **characterization 测试**
   - 作用：把当前正确行为钉住。
   - 这些测试在当前代码上**允许直接 PASS**。
   - 如果它们直接 PASS，记录为“当前行为基线已被现状满足”，然后继续；禁止为了追求形式上的先红而故意改坏现有行为。
2. **边界护栏测试**
   - 作用：防止 shared owner、media owner、launcher/bootstrap owner 再次漂移。
   - 这类测试有些会先 FAIL，有些也可能直接 PASS。
   - 只要它们真实保护本轮边界，就都有效。

因此必须写死：

1. **禁止为了满足教条式先红，故意把现有正确行为做坏。**
2. **禁止看到 characterization 测试先绿，就误判“这一步没价值”。**
3. **总收口阶段真正的 TDD 含义，是先补行为和边界护栏，再在重构中持续保持这些护栏为真。**
