# 纯Rust群聊项目实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付一个可在 Win11 本地一键开发、在 Linux 服务器可部署的纯 Rust 群聊 MVP，覆盖匿名会话、房间短码、入房/建房、文本聊天、成员与基础治理、Telegram iOS 深色版风格 Web 外壳。

**Architecture:** 采用 `web + server + core` 三 crate 结构。`core` 承载契约、领域模型、用例和 ports；`server` 负责 HTTP/WebSocket 入口与基础设施装配；`web` 负责 Telegram 风格 UI 壳与前端交互。所有实现遵守 DDD、TDD、代码即文档、边界优先。

**Tech Stack:** Rust workspace, Dioxus, axum, tokio, serde, sqlx, PostgreSQL, tracing, thiserror, anyhow, uuid, time

---

## 范围说明

本计划聚焦第一版可工作的 MVP，不包含图片、文件、语音、搜索、推送、复杂多端同步。

本计划默认：

- 基础设施层 100% 复用成熟轮子
- 业务规则只在 `core`
- 先端到端打通，再做局部打磨
