# 原生一键安装部署 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 `koko` 增加第一版 Ubuntu/Debian 原生一键安装部署骨架，包含安装/升级脚本、systemd 模板、Caddy 模板和配套文档。

**Architecture:** 保持业务内核不变，只在部署壳层新增 `deploy/` 骨架。安装器使用预编译产物 + `systemd` + `Caddy` + `PostgreSQL`，不引入 Docker，不要求服务器现场编译源码。

**Tech Stack:** Bash, systemd, Caddy, PostgreSQL, existing SQL migrations
