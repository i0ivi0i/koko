# socket.io 前端资源收口与官方最新版对齐 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不引入 npm/pnpm、不手搓新轮子的前提下，把浏览器侧 `socket.io` 客户端收口到官方最新版 `4.8.3`，统一前端资源、入口页面、运行时路径与测试真相。

**Architecture:** 本次继续复用 Rust 侧 `socketioxide` 与 Dioxus 资产管线，只替换浏览器 vendor 资源并把官方 bundle 接到 `Dioxus.toml [web.resource].script`。`src/web.rs` 只消费入口层已注入的全局 `io`，不再靠组件树注入脚本或动态导入决定时序。实现坚持最小改动：不新增私有预加载器，不重写 realtime runtime，不扭曲 `assets -> dist/public/assets` 的边界。

**Tech Stack:** Rust 2024, Dioxus 0.7, socketioxide 0.18.2, Axum, PowerShell 5, cargo test, dx bundle

```rust
#[test]
fn bundled_index_preloads_socket_io_before_wasm_bootstrap() {
    let html = std::fs::read_to_string(
        Path::new(env!("CARGO_MANIFEST_DIR"))
            .join("dist")
            .join("public")
            .join("index.html"),
    )
    .unwrap();
    let socket_io = html.find("socket.io.min.js").unwrap();
    let wasm_bootstrap = html.find("/wasm/koko.js").unwrap();

    assert!(socket_io < wasm_bootstrap);
}
```
