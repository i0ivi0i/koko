# xtask 开发入口与 run 脚本薄壳化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立 `cargo xtask dev` 作为唯一推荐开发入口，并把 `run.ps1` 收口成只负责 Windows 参数转发与退出码透传的薄壳。

**Architecture:** 本次把开发编排从 PowerShell 收回 Rust/Cargo，但不触碰 Rust 主程序的服务真相。`xtask` 负责数据库准备、bundle、构建、启动与可选 auto-open；`run.ps1` 只负责参数映射转发；Rust 主程序继续独占首页地址、管理入口、管理员口令与 ready 真相。

**Tech Stack:** Rust 2024, Cargo workspace, `.cargo/config.toml` alias, PowerShell 5, cargo test

---
