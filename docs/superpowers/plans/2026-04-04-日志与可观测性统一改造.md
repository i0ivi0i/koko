# 日志与可观测性统一改造 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 `koko` 在开发环境和未来 Linux 生产环境下都能持续输出足够排障的 Rust 日志，同时保持 Rust 是唯一真实日志源。

**Architecture:** 保持 `src/support.rs` 为唯一 tracing 初始化入口，只用一套适合 `stdout/stderr` 的人类可读 formatter。HTTP 只给 `/api/**` 挂基础 `TraceLayer`，realtime 只补关键 success / reject / failure 日志，不引入 `request_id`、JSON/OTel、应用内落盘或专门日志测试基础设施。

**Tech Stack:** Rust 1.94, `tracing`, `tracing-subscriber`, `tower-http::trace::TraceLayer`, `socketioxide`

```rust
pub fn init_tracing(default_filter: &str) -> Result<TracingInit, Infallible> {
    let filter =
        EnvFilter::try_from_default_env().unwrap_or_else(|_| EnvFilter::new(default_filter));
    let subscriber = tracing_subscriber::fmt()
        .with_env_filter(filter)
        .with_target(true)
        .compact()
        .finish();

    let result = match tracing::subscriber::set_global_default(subscriber) {
        Ok(()) => TracingInit::Initialized,
        Err(_) => TracingInit::AlreadyInitialized,
    };

    Ok(result)
}
```
