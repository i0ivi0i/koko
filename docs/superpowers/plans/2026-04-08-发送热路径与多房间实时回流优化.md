# 发送热路径与多房间实时回流优化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不改变领域真相与共享契约的前提下，压薄单机内多房间群聊的发送热路径，让同房消息仍然绝对有序、跨房间更少互相拖累、发送者更快收到权威消息回流。

**Architecture:** 保持“先落权威事实，再广播”的主链不变，只收口 `src/外壳.rs`、`src/适配.rs`、少量 `src/用例.rs` 里的热路径组织与事务边界。优化遵循 TDD：先补失败测试，再最小实现，再验证不破坏补洞和广播语义。

**Tech Stack:** Rust、Tokio、Axum、socketioxide、SQLx、PostgreSQL、cargo test

---
