# 真浏览器中的应用 Phase 0/1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不破坏现有聊天、媒体、上传、查看器、离线补发与 P2P 主链功能的前提下，先把 `koko` Web 前端的“浏览器应用宪法”落成第一波可执行实现：建立防漂移门禁、把平台事件统一收进 `AppRuntime`、引入 `AppLifecycleActor` 作为生命周期真相 owner，并清掉现有最明显的浏览器 API 越层口子。

**Architecture:** 这一波只做 `Phase 0/1`，不把后续所有 owner 收口、预算化、多上下文治理和长期 P2P 平面一次塞进同一批改动。前端继续复用已有成熟轮子：平台组合根继续是 `BrowserAppPlatform`，生命周期 owner 复用现有 `xstate` 模式，不手搓第二套状态机框架；Lit 继续只做壳层，`AppRuntime` 升级成 UI 事件与平台事件的唯一前端入口，`聊天应用内核` 不再直接订阅平台事件，`媒体协作分发` 不再直接碰 `navigator.storage.persist()` 与裸存储句柄。

**Tech Stack:** TypeScript, Lit 3, xstate 5, Vitest, Workbox, WebTorrent, socket.io-client, localStorage-backed repos, existing BrowserAppPlatform runtime modules

---

## Scope / Constraints

1. 本计划只覆盖 [真浏览器中的应用宪法与防漂移治理设计](E:/koko/docs/superpowers/specs/2026-04-17-%E7%9C%9F%E6%B5%8F%E8%A7%88%E5%99%A8%E4%B8%AD%E7%9A%84%E5%BA%94%E7%94%A8%E5%AE%AA%E6%B3%95%E4%B8%8E%E9%98%B2%E6%BC%82%E7%A7%BB%E6%B2%BB%E7%90%86-design.md) 的 `Phase 0/1`：立宪门禁 + 生命周期主权收口。
2. 这不是“全前端一次性 actor 化”计划；`RoomTimeline / RoomViewport / MediaRuntime / RealtimeSession` 的全面独立 owner 收口留到后续计划。
3. 必须遵守 DDD + Unix 哲学：真相 owner 清楚、模块小而专、复用成熟轮子、不新造私有框架、不让新层与旧层并行活着。
4. 必须用 TDD；每个 Task 都先补失败测试，再做最小实现，再转绿，再提交。
5. 这轮默认在现有 `main` 工作区执行，不另开 worktree。
6. 这轮结束后必须重建 graphify：`python3 -c "from graphify.watch import _rebuild_code; from pathlib import Path; _rebuild_code(Path('.'))"`。
7. 由于本轮只做 `Phase 0/1`，后续还要再出至少三份计划：
   - 运行时 owner 全收口
   - 预算制度与大房间媒体性能
   - 缓存/更新/多上下文/P2P 长期平面对齐

```ts
import { 获取默认浏览器应用平台 } from "./平台/index.js";

private readonly platform = 获取默认浏览器应用平台();

private get 应用运行时(): 应用运行时端口 {
  if (!this._应用运行时) {
    this._应用运行时 = 创建应用运行时({
      dispatch: (command) => this.kernel.dispatch(command),
      subscribePlatformEvents: (listener) => this.platform.订阅事件?.(listener) ?? (() => {}),
    });
  }
  return this._应用运行时;
}

override connectedCallback(): void {
  super.connectedCallback();
  globalThis.addEventListener("resize", this.handleViewportResize);
  this.应用运行时.start();
  void this.kernel.dispatch({ type: "BOOTSTRAP_REQUESTED" });
}

override disconnectedCallback(): void {
  globalThis.removeEventListener("resize", this.handleViewportResize);
  this.应用运行时.dispose();
  this.kernel.dispose();
  this._应用运行时 = null;
  super.disconnectedCallback();
}
```

要求：

1. 壳层只做组合，不解释平台真相；
2. 不允许新增长驻第二份平台状态缓存。
